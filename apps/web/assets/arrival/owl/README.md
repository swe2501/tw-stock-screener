# 迎賓頁多姿勢貓頭鷹（v27 起）

`POSES.ready` 已於 v28 啟用（16 張 WebP，已依 front 自動校正 1～5px 位移）。重出某張時：照下方規格出 PNG，轉成同名 `.webp` 覆蓋，並把 `brand-arrival.js` 的 `POSES.v` 加 1 清快取。

目前檔案：front、left-20、left、right-20、right、up、up-left、up-right、down、blink、blink-left、blink-right、tilt、happy、surprised、wave。

| 檔名 | 用途 | 姿勢 |
|---|---|---|
| `front.png` | 預設 | 正面站立，眼睛看鏡頭 |
| `blink.png` | 眨眼（約 0.15 秒） | 與 front 完全相同，只有眼睛閉上 |
| `left.png` | 游標在畫面左側 | 頭轉向畫面左邊約 45°，身體不動 |
| `right.png` | 游標在畫面右側 | 頭轉向畫面右邊約 45°，身體不動 |
| `up.png` | 游標在畫面上方 | 抬頭看上方（燈泡），身體不動 |
| `tilt.png` | 閒置時偶爾 | 歪頭（好奇） |
| `happy.png` | 點擊 | 開心瞇眼 |
| `surprised.png` | 點擊頭部 | 驚訝，眼睛睜大 |
| `wave.png` | 點擊 | 單邊翅膀揮手 |

## 出圖規格（每一張都要一樣）

- PNG、**透明背景**、正方形 **1600×1600 px**。
- 貓頭鷹全身置中；**頭頂在畫面上方約 8%、腳底在畫面下方約 94%**，每張的腳位置、身體大小完全一樣（只換頭部／翅膀／表情）。
- 同一個鏡頭（正面、與貓頭鷹胸口同高）、同一個光源（正上方偏前的暖色燈光），無地面陰影、無文字。
- 第一張先出 `front.png`，之後每一張都「以 front.png 為底圖修改」，不要重新生成整隻，否則臉型會跑掉。
