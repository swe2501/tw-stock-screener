# K 圖工具列修正（本機）

- 功能設定的展開狀態由同一入口控制，涵蓋大盤、支撐壓力、價量、分點、AI 與葛蘭碧；同時只有一個設定面板和實色選取按鈕。
- 設定面板移入工具收合區，位置在功能按鈕列後、標記工具前；收合工具時內容也一併收起。
- 現價線、法說會、除權息改放標記工具；保留獨立顯示開關和本機偏好，以淡色邊框呈現啟用，與實色面板選取區別。無事件資料時顯示停用原因。
- AI 按鈕移除 emoji；橡皮擦圖示 15px、桌面按鈕略縮小，手機仍保留觸控高度。
- 葛蘭碧標題與篩選器文字統一，圖表用中性圓點及階段1／2／3；既有計算與 API 參數不變。關閉分組設定不取消圖上已選的標記。
- 技術與籌碼分頁共用同一個標題列比例尺，切換時保留設定；技術區預設 70/15/15，籌碼區預設 K70／下方資料30。籌碼五張子圖保留原資料及高度，在下方資料區捲動檢視，避免全部擠成不可讀的細條。
- 修正籌碼頁的 MACD/RSI 選單應隱藏卻被 CSS 顯示覆寫的問題。

驗證：`tests/research-layout.browser.cjs` 使用實際圖表函式庫與隔離資料，檢查六種設定的互斥、設定位置、事件獨立開關、週期切換、同位置比例尺、真實五張籌碼畫布、分頁比例保留，以及桌面／手機與深淺外觀。

使用者選定 A 後新增：

- 法說／除權息從 K 棒箭頭移為日期軸旁「法／息」事件標籤；相近日期依 44px 最小間距合併以避免重疊，標示合併數量；原日期與明細保留於 hover／可點擊詳情中。詳細文字用 textContent，避免資料注入。
- 現價維持 1px 點線與「現價」軸標籤；支撐／壓力的各週期原始數值和線條保留，改用細點線、移除每條軸標籤，只標鄰近收盤的支撐／壓力兩項，減少重複文字；不改計算。
- OHLC 浮窗保持圖內、非固定列：比較上／下及左右候選位置，依 K 棒與游標重疊成本選位。高位優先下方、低位優先上方；原位置足夠安全時不移動，避免抖動；候選位置皆密集時仍優先保護正在查看的 K 棒，不保證任意密集圖完全無遮擋。
- 小時 K 日期支援數字時間；浮窗限制在繪圖區與視窗內，保留深淺背景、手機文字換行。
- 測試增加高／低浮窗避讓、真實事件軸標籤同日合併與開關詳情。
