# 自訂策略與研究式自選

## 可執行功能

策略回測頂部直接載入真實 OHLC 日K，支援代號與完整名稱搜尋、名稱建議、均線疊圖、RSI/MACD/KD/成交量副圖。修改策略參數更新指標預覽；只有按執行回測後才顯示買賣點。參數變動即清除舊結果，避免新規則配舊績效。資料不完整時拒絕產生假 K 棒。

會員可新增策略、命名、增刪買賣條件，每側最多 10 條，分別選擇全部符合／任一符合。規則提供均線、兩條均線、RSI、MACD DIF/訊號線、KD、價格突破、成交量與均量比較；每條有獨立參數。可儲存、重新載入、複製、改名、刪除及復原策略；最多 50 個。範例是可修改的初始值，不是唯一可用策略。

每次回測保存當次完整策略與資金參數快照；修改原策略不改舊紀錄。回測可匯出 JSON、載入當次設定重跑、轉為研究筆記。

我的自選改為精簡標的清單＋連動 K 圖與研究詳情。每列呈現理由摘要；選中後讀取該標的歷史行情與資料日、最新收盤及相較前一根日K的漲跌。未讀行情的標的顯示破折號，不虛構即時報價。分類可用頁籤切換，保留改名與上下排序。新增標的統一先開 K 圖再收藏，不在清單及搜尋結果放星星。

研究詳情保存收藏理由、下一個確認點、重新評估條件與下次研究日期。收藏理由透過既有帳號 watchlist 同步；其他研究欄位目前保存在本機。未送出理由先留本機草稿，並明確顯示尚未同步。能連至完整技術分析、技術觀察、策略回測、研究筆記與 ETF 配息。

## 計算定義

- SMA 使用 N 根收盤算術平均；EMA 以前 N 個有效值 SMA 作種子，平滑係數 2/(N+1)。
- RSI 使用 N 日平均上漲／下跌幅初始化，再採 Wilder 平滑；完全不變為 50、只有上漲為 100。
- MACD DIF＝快 EMA−慢 EMA，訊號線為 DIF 的 EMA。
- KD 的 RSV 使用含當根的 N 根最高／最低價；K、D 初值 50，分別用會員指定平滑參數更新。區間高低相同時 RSV＝50。
- 價格突破以前 N 根最高／最低價比較，成交量以前 N 根平均量比較，皆不含訊號當根。
- 高於／低於為持續條件；由下往上／由上往下穿越須同時檢查前一根與訊號當根，不能混用。
- 條件資料不足不補零、不當作有效訊號。開始日前須有完整暖機資料。

## 成交規則

收盤條件在下一個有效日K開盤執行。只做多、單一部位、不加碼不槓桿，整數股；可選可用現金比例或固定金額。賣出當天不重新買進。停損／停利從實際模擬買價計算，跳空按開盤價；同棒雙觸價採停損優先，並列在規則摘要。最長持有以日K根數計，達上限後下一根開盤退出。

期末未賣出部位按最後收盤估值；勝率只計已平倉交易並扣費稅。最大回撤使用每日收盤權益，非盤中回撤。買進持有基準使用全額資金與相同買進費用／滑價，不強制期末賣出。

日期範圍內有分割事件時拒絕回測；日期範圍之前的最後分割事件作為指標重新暖機起點，資料不足仍拒絕。預設排除今天的未確認日線。

## 尚未開通與限制

策略、自選分類、技術觀察、研究脈絡及回測紀錄仍為依會員 ID 區分的本機資料，未接雲端私人表。既有股票收藏與理由沿用原帳號服務。無自動通知、無真實交易委託。

目前只支援日線、第一層 AND/OR 條件，尚無巢狀括號、空單、加碼、多標的投資組合與會員自寫程式。回測不含配息、最低手續費、流動性、漲跌停排隊與真實券商成交限制。
