# 首頁盤面結構：成交比重週期比較與點選明細

2026-10-18 使用者確認：保留電子／金融／傳產儀表、原研究參考門檻與櫃買比較；主結論改為實際變化，不再由電子占比直接下主攻／多頭結論。週期以精緻下拉選單呈現，避免六個按鈕擠在畫面。

## 資料與計算

- 沿用公開 `sector_turnover`、`taiex_daily`、`otc_index_daily`，只擴大既有查詢歷史長度；不新增 API、不修改資料庫／Auth／排程／App。
- 週期：今日、3日、5日、10日、20日、60日。最近 N 個交易日對比再往前 N 個交易日，兩段不重疊；不是 N 個曆日。
- 交易日依加權日線日期對齊，占比使用其最新可對齊資料日；指數較新時明確提示，不混用不同日期。
- 有完整原始金額：`Σ類別成交金額 ÷ Σ上市成交總額 × 100%`。每個期間獨立求和，不是平均每日百分比。
- 原始金額不完整、但占比完整時：本期與前期一律改採「每日占比平均」，明確標示非金額加權。缺少的金額不從占比反推。
- 本期／前期各自必須有 N 日完整有效資料；內部缺日也會判定不足，不跳過缺日去湊別的日期。若只有本期完整，可看本期值但前期與增減顯示 —。
- 指數期內漲跌：本期最後日收盤 ÷ 本期開始前一交易日收盤 − 1；缺少邊界或期間內指數資料不計算。櫃買同理。
- 合法的 0% 不當成缺值；前期類別成交金額為 0 時，不顯示無限大增幅。負金額、重複日期、無效日期、矛盾總額與不合理占比不當成有效紀錄。
- 占比差值以原始精度算，顯示四捨五入。±0.05 個百分點內顯示接近前期，只是配合一位小數的呈現容差，不是經驗證的交易門檻。

## 畫面與判讀

- 主畫面：保留三個半圓儀表，增加前期占比、占比增減、成交金額增減與可點選提示。只放一個週期下拉。
- 摘要合併同期加權方向與變化最大的類別，例如「加權上漲，電子成交比重降低」。電子占比高不等於上漲／淨流入。
- 點圖卡：桌面開置中明細，手機開底部面板。沿用所選週期，關閉回原圖卡；支援 Enter 開啟、Escape 關閉、焦點返回。
- 明細：四項核心數字、兩段日期、相對金額變化原因、可切占比／成交金額的歷史 SVG、滑鼠與鍵盤日期讀值、六週期比較。
- 金額理由分開處理「類別金額下降但全市場下降更多，所以占比提高」等情況，並列類別與上市總額各自的金額增減，不把占比提高當成資金淨流入。
- 歷史圖保留缺口，不跨缺日連線；本期／前期底色與占比虛線可查核。深淺色以網站 CSS tokens 即時更新，不重抓資料或重設週期。
- 六週期小格僅是明細對照，不是六顆操作按鈕。期間有重疊，不做獨立訊號投票。
- 延伸：同週期歷史占比百分位（至少 60、最多 252 筆完整前期樣本，不含本期）、最近五次相鄰交易日的占比提高／降低次數。
- 類股自身指數、類內漲跌家數與個股成交排名尚未由現有查詢取得，明確標示未取得，不以加權代替類股方向。沒有產生個人買賣建議。
- 原電子 55／65／75／85%、金融 10%、單一傳產 15% 與原文字規則保留在可展開「原研究參考」；不再呼叫舊 evalStruct 作主結論。既有櫃買／集中區塊保留為最新單日比較，明確標示不隨新週期切換。
