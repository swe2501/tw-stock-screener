# 自訂公式與中文引導（第一版）

公式是受限制的時序語言，不是 JavaScript／Python。每個買進或賣出條件各有一段程式，最後一行必須產生布林條件。訊號以當日收盤資料判斷，下一根日K開盤模擬成交。判定成立不代表一定買進：資金、持倉、賣出當日不再買進等規則仍有效。

## 寫法

```text
param period = 20
param multiple = 1.5
trend = SMA(close, period)
priorVolume = REF(SMA(volume, period), 1)
close > trend AND volume > priorVolume * multiple
```

也可使用中文別名與中文變數：

```text
參數 週期 = 20
趨勢線 = 均線(收盤價, 週期)
收盤價 高於 趨勢線
```

宣告與運算每行一個；亦可用分號分隔，`#` 後是註解。名稱可用字母、中文、底線與後續數字，最多 32 字，不得與欄位、函式或保留名稱重複。先宣告後使用，不允許重複賦值或循環引用。參數宣告為數字，編輯器另提供數值覆寫；修改程式會重設覆寫，顯示標準語法則保留覆寫。保存、匯入／匯出、回測快照均保留程式與參數。

`open/high/low/close/volume` 對應開盤價／最高價／最低價／收盤價／成交量。支援 `+ - * /`、`> < >= <= == !=`、`AND OR NOT`、`&& || !` 與括號。比較兩側須同型別，邏輯運算只接受布林；不將數字自動當成布林。比較前先算乘除、再加減；AND 優先於 OR，不確定時用括號。

## 函式

| 函式 | 定義及週期限制 |
| --- | --- |
| SMA(x,n)／均線 | 含當根的 n 根算術平均；n=2～240 |
| EMA(x,n)／指數均線 | 前 n 個有效值平均作種子，其後係數 2/(n+1)；n=2～240 |
| RSI(x,n)／相對強弱 | Wilder 平滑；完全不變為 50、只有上漲為 100；n=2～120 |
| HHV(x,n)／區間最高 | 含當根的 n 根最大值；n=1～240 |
| LLV(x,n)／區間最低 | 含當根的 n 根最小值；n=1～240 |
| REF(x,n)／前值 | 回看 n 根，0 為當根；n=0～500，拒絕負值及行情驅動週期 |
| CROSSUP(a,b)／向上穿越 | 當日 a>b 且前日 a<=b；不等於持續高於 |
| CROSSDOWN(a,b)／向下穿越 | 當日 a<b 且前日 a>=b |
| ABS(x)／絕對值 | 絕對值 |
| MIN(a,b)、MAX(a,b)／較小值、較大值 | 當日兩值比較；不是區間極值 |

週期可由固定數字、參數或固定數值表達式提供，不能隨行情改變。前 N 根最高價需寫 `REF(HHV(high, N), 1)`；前 N 根均量需寫 `REF(SMA(volume, N), 1)`，避免把訊號當日算入比較基準。

資料不足為 null，不補零；AND／OR 也要求兩側完整暖機，不因其中一側已為真而忽略另一側缺資料。除以零或非有限數值會指出日期及公式行欄並停止，不產生假的成立結果。公式提及成交量時需完整、非負的成交量資料，包括暖機段。

## 自然語言入口

聊天室預設是免費本機引導：可選「不知道，先介紹」，再逐步回答觀察方式、週期、比較、門檻、賣出、停損／停利／持有期限及名稱。也可先提出勝率等研究目標，依商品範圍、持有偏好及評估重點，比較公開方向後才設定參數；不把高勝率當作已驗證承諾。MACD／KD 可使用既有結構化規則，其專屬參數仍須逐項確認。按鈕數字僅是範例，使用者點選才採用。

明確句型如「收盤價高於 20 日均線，而且成交量大於前 20 日均量的 1.5 倍」可轉為待確認公式。它只支援有限句型，不推斷「強勢」「爆量」或任意長篇自然語言。生成式 AI 自由討論尚未啟用，不應將本機規則問答描述成已連線 AI。

建議不會自動改寫策略、保存或回測，須按「套用到新草稿」。若使用者已修改編輯器，舊建議不覆蓋新內容。模型提案（未來啟用時）仍須由同一公式解析器驗證；後端只驗證傳輸結構，不執行公式。

## 邊界及相容

每段最多 4000 字、60 行、600 個 token、200 個運算節點、32 層運算、12 個參數、20 個變數；每次最多 5000 根日K。數字／參數絕對值最多 1e9，二元算術結果最多 1e15。無字串、物件、陣列索引、函式定義、迴圈、動態載入、屬性存取、未來資料、讀檔或網路；未使用 eval 或 Function。
