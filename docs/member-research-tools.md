# 會員研究工具：第一版與驗收邊界

## 導覽

帳號與服務 → 會員禮遇 → 研究與學習。研究區依序為我的自選、研究工作區、策略回測、我的研究週報、學習中心。側欄不使用獨立捲軸；淺色小標用網站藍，深色用黃色。

## 實作內容

- 收藏沿用既有 `/api/watchlist`，保留既有觀察與備註。個股與 ETF 共用清單。
- 搜尋建議、選股結果、題材成分、產業成分、ETF 總覽、ETF 探索卡與研究卡、K 線標題可收藏。ETF 成分股可經個股技術分析標題收藏；尚未在所有成分表逐列加入星星。
- 星星儲存成功才變色；減少動畫設定時不播放彈跳。會員自選頁取消收藏可復原，保留原備註與目標價。其他來源的取消目前沒有復原提示。
- 預設長期關注／等待機會／ETF；可新增、改名、上下排序、刪除分類。刪除分類不刪標的。分類限制 20 組。
- 技術觀察可填理由、日／週／月週期及選填價位／均線條件，手動結束／恢復。從 K 線建立會保留來源週期、資料日與顯示均線快照；尚未提供完整指標／繪圖設定還原。條件尚不自動判定或寄送通知。
- 研究筆記可編輯、加標籤、設定草稿／完成／封存、搜尋、暫存未提交內容、移入垃圾桶與復原、匯出。最多 20 則筆記、垃圾桶保留最近 50 則。
- 策略回測以台積電 2330 為新手範例，可改為其他股票或 ETF。支援買進持有、短長均線持有條件、價格高於均線持有條件。當收盤確認條件後，下一交易日開盤成交；第一筆交易也只使用前一日資料。
- 回測提供自訂資金、均線、手續費、交易稅與滑價。使用整數股、全資金、不放空、不加槓桿；持股按期末收盤估值，不強制平倉。勝率只計已平倉交易。基準採同樣買進成本的買進持有。
- 結果包含資產曲線、價格報酬、最大回撤、已平倉勝率、期末股數與成交明細；可存至本機、轉為研究筆記。ETF 可從自選進行情或配息研究卡。
- 週報整理最近七天筆記、技術觀察與已儲存回測，可下載。學習中心支援已讀進度、文章收藏與直接前往工具。

## 資料與限制

股票／ETF 收藏與理由使用既有帳號服務；分類、技術觀察、研究筆記、回測結果及文章收藏目前是依會員 ID 隔離的本機資料，不是跨裝置雲端同步。資料與隱私頁會一併匯出新研究紀錄。不得將大型研究文件塞入 Auth metadata。後續須由資料庫維護者審核獨立私人資料表、RLS、版本衝突處理與遷移流程，再啟用雲端同步。

回測最多使用既有行情 API 的近三年日線；不含配息、最低手續費、漲跌停排隊或成交量約束。區間內有分割事件時拒絕計算，避免未還原價格誤導；資料不足、均線暖機不足、重複日期或服務錯誤均顯示錯誤。此為教學用價格回測，不是實際帳戶績效，也尚未支援完整總報酬。

仍待擴充：批次收藏、收藏自訂排序、完整行情列表與 ETF 配息列表的站內切換、所有成分股列表直接收藏、觀察條件排程通知、雲端同步、策略重新載入／比較、週報心得與下一週待辦。

## 2026-10-16 自選操作更新

- 新增收藏區有明確輸入框，選取建議後按「收藏」加入帳號自選；搜尋選取本身不開啟 K 圖。首頁點選事件只接受 `#hpSearchDrop` 內的選項，避免會員中心搜尋在背景開啟股票。
- 會員 K 圖固定提供 5／10／20／60／120／240 日均線開關。5 日黃、10 日藍、20 日紅、60 日橘、120 日紫、240 日灰藍。自訂策略所需的額外均線另外顯示；顯示開關不改變回測規則。
- 「最近移除」逐筆保留這次開啟會員中心期間取消的股票及其收藏理由、到價條件。各檔可獨立恢復，離開會員中心或切換帳號後清除恢復清單。分類與研究脈絡不因取消收藏被刪除。
- 分類管理使用置中的原生 dialog：上方新增、點名稱改名、顯示檔數，「⋯」內可調整順序或刪除。刪除分類保留股票；分類目前仍為本機資料。
- 完整 K 圖只是開啟分析。技術觀察儲存在「我的自選 → 技術觀察」；研究筆記儲存在「研究工作區」；策略回測須執行後保存才會出現在回測紀錄。這些入口標明去向，不會在點擊時自動建立相同的收藏。
- 完整 K 圖的收藏理由同步帳號自選；到價條件在完整 K 圖的設定區查看。手動模擬交易仍在原 K 圖功能中，與策略回測紀錄分開。
