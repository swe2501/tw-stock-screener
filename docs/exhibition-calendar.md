入口：題材族群 → 話題族群。沿用原本話題頁的授權可見範圍，本次不更動會員或 Auth 規則。

## 資料與來源

- `apps/web/assets/exhibitions.json`：2026-10-24 逐一查核主辦單位公告，11 場已公布展期及 1 場延期活動；每場保留 sourceUrl、verifiedAt。只收錄已核實日期，不用去年日期推算。
- 分類透過網站既有 themecatalog、industries API 與 _loadNames 讀取；不將完整資料庫分類或名單快照放入 GitHub。公司關聯取自既有分類，不推論參展。
- 公司證據獨立保存 kind、date、title、sourceUrl。只有當屆參展證據能標示 exhibitor；technology 是公司技術消息，不等同參展。往年參展不自動延伸為今年參展。
- BIO Asia–Taiwan 的大會 7/27 起，但實體展覽為 7/28–7/31；SEMICON Taiwan 2027 已改到 8/18–8/20。FinTech Taipei 原訂 10/23–10/24 已延期，新日期未知，不能繼續以原展期倒數。

## 提醒與介面

以 Asia/Taipei 的日期計算。開展前兩個曆月起（月底不足天數向下截齊，例如 1/31 → 11/30），到開展前一天列為展前提醒，展期間改為進行中，結束後不再列入未來清單。未定／延期日期沒有提醒起日。本站本頁顯示提醒；沒有發送 Email、瀏覽器通知、推播或新增排程。

月曆顯示展期每一天，點選右側原生 dialog 抽屜，支援 Escape／背景關閉及焦點返回。可依全體題材／官方產業、展覽關鍵字、月份及個股名稱代號篩選，個股可帶入既有 K 線。手機月曆可區內水平捲動，抽屜改滿寬，明暗配色沿用網站變數。

## 更新方式與限制

展覽日期這一版是已查核的資料快照，尚未接自動抓取或通知服務；分類則於開啟時從既有網站 API 讀取。展期、公司證據有變動時需先查主辦單位／公司公告，再更新 JSON 與 verifiedAt。不要只改核對日期而沒有查證。超過 30 天會顯示需要核對主辦單位的提示。資料涵蓋的是已核實活動，不能宣稱所有產業未來展覽已完整涵蓋。

更新既有事件時保持 id；延期／取消應移除 start/end、修改 status 及註明公告來源。資產版本更新時同步調整 JS 的 展覽 JSON URL query 與 index 引用版本。任何排程、DB schema／寫入或 Auth 調整需另行授權。

## 本機載入相容（2026-10-25）

`exhibitions-data.js` 是 `exhibitions.json` 的等內容公開展期快照，供 file:// 無法 fetch JSON 或靜態路徑回傳錯誤時使用；修改展期時必須同步生成，瀏覽器測試核對兩份資料完全一致。JSON 仍為維護來源。分類端點失敗／無有效 themes／逾時不阻擋展期呈現，畫面明示分類不可用並可重試；不以展覽題材推測個股名單。查詢失敗時保留官方來源，相關個股不顯示假空集合結論。
