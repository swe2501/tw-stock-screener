# 部門任務中心操作

管理後台 → AI 研究室 → 任務中心。也可在金融大廈點部門名片的「指派任務」或「查看部門任務」。

## 派工與驗收

### 免費內容營運（人工流程）

任務中心的「建立內容流程」可先填主題、讀者及交付需求，確認後建立四站：資料與金融研究部 → 內容與教育部 → 法遵與風險管理部 → 總經理辦公室。所有任務均為人工執行、AI 預算為零，不會啟動模型、排程或發布工具。

各站沿用既有領取、提交與驗收規則；前置任務未驗收不能領取下一站。後續執行人須開啟前置任務閱讀完整成果。執行人不可自行驗收，需由另一位有權限的管理者審查。法遵為內部初審，未解決事項須交專業人士確認，不能視為法律保證。

最後一站的驗收代表核准該內容版本，不代表已發布；正式發布需由有權人員另行操作及記錄渠道、連結與時間。免費提供不等於免除合規義務。連線失敗時可在原視窗按「繼續建立」，沿用識別碼重試；未完成的部分任務已存在時不會回滾刪除。

1. 建立任務：名稱、負責部門、任務內容、逐行驗收條件、截止日期。選擇人工執行或 Claude AI 研究／草稿；AI 需核定美元預算。
2. 人工任務按「領取並開始」，回報進度／卡點，完成後提交成果。AI 任務由本機執行端領取；未在線時留在待執行。
3. 在任務卡查看負責部門、實際回報、期限、卡點、執行方式及驗收狀態。點卡片看成果與完整任務紀錄。若版本已更新，按「重新載入」再操作。
4. 待驗收時逐項勾選條件後通過，或填退回原因並「退回修改」。AI 不會自己驗收。已驗收成果不可直接取消。
5. 「交接給下一部門」建立有前置依賴的新任務，帶入前置成果。也可在建立表單選前置任務；未驗收前不會領取。執行器會收到已驗收成果的有界摘要，截斷會註明。

任務狀態：待執行 → 執行中 → 待驗收 → 已驗收；異常可為卡住、失敗、取消。三分鐘未回報的 AI 租約可由管理者標記中斷，不會自動重跑付費任務。若費用不明會按已保留預算估計；無剩餘額度時需明確建立新任務。單項最多領取三次。

## 本機執行端

需既有 Claude CLI 登入（`claude auth status`）。不要另建 API 金鑰或把資料庫金鑰填入任務內容。執行器不使用 Bash、檔案或部署工具，任務只交給 Claude 的研究工具與草稿產出。

在完整專案工作區啟動：

```powershell
python scripts/office_task_worker.py --env-file C:/Users/User/Desktop/AI_stock/.env.local --daily-budget-usd 0.50
```

使用現有本機服務環境，但不修改該檔。不要同機開多份執行器。單次巡查可加 `--once`。停止使用 Ctrl+C；若強制結束，網站會在心跳逾時後顯示離線，進行中的任務可按「標記執行端中斷」。

本次不安裝常駐服務或工作排程。電腦關閉後不能繼續本機執行；任務紀錄仍在雲端保留。原新聞、資料與總管排程不受影響。

## 限制

### 每日巡檢與 KPI（2026-11-06 第一階段）

- 已在本聊天建立每日台灣時間 09:30 的全公司巡檢與提案排程（名稱：先見每日全公司巡檢與 KPI），與每週一 09:00 三個去重教學主題提案分開執行。
- 本聊天排程不等於雲端執行器已部署。它只讀已有授權的紀錄與公開來源，將待辦、異常、產品改善及需核准事項回報本聊天；不建立正式網站任務、不自動發布、投放、採購或修改正式站。沒有管理資料權限時標示未串接，不繞過權限。
- 32 部門的責任、交付物、下一站與待串接業務 KPI 定義在 `apps/web/assets/ai-office/office-operations.js`；31 個啟用部門共用巡檢，物流維持停用。不是 32 個模型各自常駐。
- 工作室的已驗收交付數、準時率及異常數依已載入任務計算。近 7 日與前 7 日比較；時間以已驗收 history 事件為準，準時以台灣日期比較期限。樣本不足不算達標，資料缺漏不計為零。最近任務視窗不代表全量 KPI，介面明示限制。
- 個人績效、註冊轉換、社群觸及、廣告成效、真實收入等，需另接事件與業務資料。尚未串接前只顯示指標定義，不杜撰分數。不以每天數字上升作硬性要求，也不為填績效製造無效任務。
- 後續全天雲端建議使用事件／定時觸發的執行器與共用佇列；預算保留、每日／每月硬上限、模型實際費用、重試上限與發布核准必須由後端控制，不能只靠模型提示或帳單提醒。尚未啟用額外付費服務。

- 派工目前只在 UAT 開放；雲端資料與正式站共用同一專案，但新任務用獨立命名空間，不寫行情、會員或其他任務資料。
- 31 個啟用部門共用一個按角色提示執行的 Claude，不是 31 個常駐模型。
- 工程、廣告、財務等部門可以產出規格／草稿；不會因此自動部署、投放、付款、寄信或修改網站資料。
- 本機執行端以 20 秒巡查、每次一項工作，預設每日估計額度 US$0.50；達上限保留待辦，不假裝執行中。用量以 Claude 帳號為準。
