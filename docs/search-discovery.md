# 網站搜尋探索面板

入口：導覽列「股票代號、名稱或站內資訊」。電腦為浮動面板，600px 以下全螢幕並顯示返回鍵；搜尋框沿用同一個元素與鍵盤操作，手機鎖定底頁捲動與焦點，返回／Esc 後還原。左右滑動或聚焦排行按方向鍵可查看 ETF。

搜尋紀錄存在目前瀏覽器 localStorage 的 academy.search.history.v1，最多 10 筆、最近選取優先，不傳送資料庫、不跨帳號/裝置同步；畫面標示「此瀏覽器」。支援一鍵清除與其他分頁的 storage 更新。

排行依成交值而非捏造瀏覽熱度：股票優先讀既有 page_cache kind=overview（4 天內預算快取），缺資料才退既有 overview API；ETF 使用既有 etf_products 最新資料日。兩張卡各自顯示資料日期，紅漲綠跌，缺漲跌不是零。點股票／ETF 開既有完整 K 圖，看更多開既有總覽頁。

話題優先讀 hot_topics 熱度排序；空表時改用既有 news_feed 的最新收錄新聞，標示切換後的排序依據與來源日期，排除彩券開獎標題。外部來源只允許 http/https 且不得夾帶帳密，沒有連結則查站內相關內容。來源與使用者文字統一跳脫，不插入原始 HTML。

三個區塊平行、獨立顯示，10 秒逾時，不因慢來源抹掉已完成區塊；記憶體快取 5 分鐘，使用者可重新整理。不新增 API／資料表／排程，不修改 App、會員權限或正式站。

驗證：7 項資料/歷史/安全/非阻塞載入單元測試；JavaScript 語法與 API 預算 12/12；Chrome 實際 UI 操作驗證 390px、320px、1440px、明暗、搜尋開 K 圖、歷史紀錄與清除、返回、背景捲動還原。既有 site-search.browser.cjs 已更新全螢幕預期；本輪 UI 驗證透過 Chrome 操作工具完成，未宣稱其 headless 腳本已跑過。
