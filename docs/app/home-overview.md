# App 首頁／總覽

首頁由 `apps/mobile/src/HomeScreen.tsx` 呈現，使用現有 App 專用後端，沒有新增 API、資料表、排程、會員權限或 Vercel 設定。

- 加權指數：`market_summary`；顯示官方收盤點位、較前一交易日變動、上市市場成交金額及資料日。成交金額由 TWD 換算億元，不當成指數成交金額或即時報價；缺少數據不顯示零。伺服器 stale 及更新失敗沿用舊資料均明示。
- 研究快訊：沿用 `site_search`，台股／AI／半導體／光通訊四個關鍵字，首頁每次顯示四筆。這是關鍵字搜尋，不是全部新聞的熱門排行。每則顯示日期、來源、摘要及 HTTPS 原始連結；缺資料、部分失敗、逾時分開處理。
- 首頁搜尋及查看更多會帶入研究搜尋頁並執行查詢。空關鍵字清除舊查詢內容。集團研究明示開啟網站；原生集團資料與自選同步未因此實作。
- 首頁保持掛載，切分頁不重載資料；重新整理才主動重抓。切換題材會取消舊請求並忽略過期結果；請求上限十五秒。換分頁回頂端。
- 手機單欄，768px 起雙欄；題材籤可水平捲動，文字容器可伸縮。沿用系統深淺色，沒有新增套件。iPhone 實際排版、字體放大及 iPad 分割畫面仍需真機驗收，不以編譯結果宣稱視覺驗證完成。

驗證：十七項 auth／首頁資料測試與 TypeScript 通過；使用首頁客戶端實測線上大盤與四組關鍵字均成功。行情資料日為 2026-10-16，四組搜尋皆回八筆，無 partial。這是當次測試結果，不代表即時資料保證。iOS／Android 原生匯出及 SDK 57 Expo Go bundle 另於發布時檢查。
