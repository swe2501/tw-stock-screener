# 原生導覽與版面修正 · 2026-10-18

依使用者要求：功能必須是清楚可點的入口、再分支到詳情；不接受以手機網頁作為 App 主體。修正窄螢幕與深淺色不一致，保留網站藍白／深金風格。

## 導覽

底部五入口為大盤、探索、研究、策略、我的；每個入口先顯示原生功能卡，點入有一致返回列，Android 詳情返回鍵回到功能總覽。已造訪的主要工作台保留表單狀態；切色不重建整個 App、不清除草稿。

| 分區 | 功能入口 |
|---|---|
| 大盤 | 今日摘要、指數 K 圖、三大法人、融資融券、市場廣度、資金結構、期貨籌碼、選擇權 |
| 探索 | 股票搜尋、ETF 探索、條件選股、熱門題材、產業族群、集團研究、市場新聞 |

資金結構、期貨、選擇權、題材、產業、集團、新聞、交易工作台、價格提醒、通知、邀請仍有未接通的原生資料或流程，入口明示規劃中，點入說明狀態，不跳轉網站、不製造行情。會員頁明示 Expo Go 登入限制。本輪沒有實作交易紀錄儲存、通知發送或付費 AI。

主導覽不再載入 MarketHome／FeatureDirectory 的網站畫面；原檔保留作先前階段與網站章節映射參考，尚未代表全部網站功能已原生完成。K 圖使用隨 App 打包的圖表 renderer，讀取公開行情，不載入網站頁面。

## 修正

- 功能卡採向量圖示、藍白／深金配色、可伸縮等寬欄、輕壓彈回；窄螢幕或系統字體放大切單欄，平板最多三欄，減少動態時停動畫。
- 移除跟隨系統／三態循環。上方按鈕只切深／淺，設定頁兩個明確選項。讀取偏好完成後才顯示主畫面，避免先畫錯色；保存按序排隊。同步原生 Appearance、狀態列與輸入鍵盤；舊 auto 值轉為淺色。
- 圖表以商品及色系作 WebView key，切色重建本機圖表，避免沿用舊圖表底色；外層背景也同步。
- 指數成交卡窄版單欄、名稱與數值可換行，避免硬性最小寬度。回測成本與風控欄位改為可捲動單欄；股票長名稱與價格在窄版上下排列。
- 搜尋與選股表單搬到 FlatList 的可捲動 header，避免上方表單吃掉所有高度，使結果看不到。價格區間與最低成交股數採 AND，輸入非負數、上下限檢查；按實際盤後資料篩選，不提供績效推論。
- 研究筆記可直接篩出已有筆記的公司；從自選跳回搜尋會清除不相關篩選，保留指定公司詳情。
- 策略庫與編輯入口分開；空策略庫明確說明新增位置。聊聊縮成小圖示，減少遮蓋；聊天室增加 iOS 鍵盤避讓。

## 驗證方式與限制

- 34 項 App 自動測試通過，涵蓋切色保存／重開／保留草稿、放大字體導覽、獨立市場區塊、原生返回、條件選股與既有回測／備份流程。
- TypeScript、Expo Doctor 21/21、網站公式引擎一致性、iOS／Android Hermes 匯出通過。
- `npm run review:layout` 僅開本機 8087 元件驗收。`tests/mobile/layout.browser.cjs` 使用相同 TSX 的 RN Web 渲染及明示測試行情 fixture，測 320×568、390×844、768×1024、1024×768、844×390 深／淺共 110 個視窗／導覽情境，無橫向溢出、切色或 JS error；檢查稿在 dist/layout-review（忽略版控）。測試行情不進 App 產品資料。
- React Native Web／react-dom／metro-runtime 僅開發驗收依賴；原生發行平台仍 ios/android。本機驗收不是把 App 改成網頁，也不代替 iPhone／Android 實際 Yoga、鍵盤與原生手勢驗收。舊 iPhone 原生模組錯誤不能據此宣稱已解決。

本輪只修改自己的 App worktree／app 分支，無網站、共用 API、Auth、正式資料庫、UAT、prod 或 Andrew 分支修改。SDK57 保持隔離。
