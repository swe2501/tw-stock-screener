# 點數帳戶逐筆紀錄（網站）

範圍：`apps/web`、網站隔離測試。沿用既有 `member_wallet_summary` 及本人唯讀 `member_point_ledger`，沒有新增 API、執行 SQL、啟用儲值或改變點數核發／兌換規則。App 不受影響。

- 點數帳戶提供「任務點數／儲值點數」兩個可鍵盤切換的分頁。餘額由伺服器查完整流水，與列表已載入筆數獨立。
- 任務流水顯示伺服器入帳日期與時間（台灣 UTC+8、到秒）、來源分類、原始內容、正負點數、紀錄編號與已入帳狀態。無編輯／刪除入口。
- 日期區間與獲得／使用篩選送往既有本人 REST 查詢。每頁 50 筆，額外取一筆確認後續頁；`created_at,id` 複合游標保留微秒，查詢截至伺服器核對時間，避免只提供最近 100 筆。來源分類不能確認時標為其他異動。
- 可下載篩選後已載入紀錄的 UTF-8 CSV，檔名標明筆數，不宣稱為全部流水；文字轉義防止 HTML 與試算表公式注入。
- 請求與目前掛載頁／帳號 token／查詢代次連動，切頁或換帳號的舊回應不覆寫。失敗與零筆紀錄分開呈現，可重新查詢或重新整理。
- 儲值目前未接付款服務，獨立分頁明示尚未開放、餘額不冒充 0、不顯示假交易。未來訂單／付款／入點／消費／退款欄位及規則列為待接服務，不提供付款操作。
- 現有流水缺少逐筆效期、沖銷關聯及交易後餘額，說明中明示，不從截斷列表倒推。此次不聲稱完成儲值對帳、退款或法律條款。
- 深淺背景沿用站內色彩變數；桌面對齊列表、手機明細卡片，320／375px 無水平溢出。

驗證：`tests/member-wallet.browser.cjs` 使用隔離行情與帳號資料，涵蓋真實網站入口、既有 Identity 查詢、日期／正負篩選、複合游標微秒與後續頁、來源／明細／台灣時間、CSV、錯誤重試、跨分頁延遲回應、未開放儲值、深淺背景及手機排版。無正式點數寫入。

網站為靜態原始碼，無 npm build 目標；檢查 JavaScript 語法、瀏覽器整合、API 數量與修改邊界。尚未提交或推送 UAT。
