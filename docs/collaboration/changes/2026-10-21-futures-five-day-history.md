# 首頁期貨摘要：五日走勢

範圍僅網站；保留點數帳戶與先前成本卡未提交修改，不發布 UAT、不動 API／資料庫／App。

- 既有 `futures_daily` 唯讀查詢由最近 1 筆改為最近 5 筆，沿用日期、外資淨額與小台／微台多空比欄位。已唯讀確認既有資料包含五筆歷史值；無新增端點或排行／期貨計算。
- 外資摘要下方為零軸柱狀圖；淨多紅、淨空綠。較前日採淨多／淨空增加減少及轉向敘述，避免將淨空減少誤寫成淨空增加。
- 小台、微台為折線圖，採同一個以零為中心的刻度；下方顯示最新較前日幾個百分點。這是部位資料變化，不是多空交易建議。
- 每個交易日可滑鼠、觸控或鍵盤選取，顯示完整資料日期及數值；歷史讀值與最新變化分開標示。沒有新資料時不冒充今日行情。
- 缺漏值不轉成零，折線缺值斷開，不補線；歷史不足五筆會標註實際筆數。空資料／讀取失敗顯示暫時無法讀取。
- 三張卡的圖表區下緣對齊，與成本卡維持等高；深淺背景用站內 surface／border 變數及分別調整過的紅綠藍線條，細緻進場光效尊重減少動態設定。

驗證：`tests/futures-summary.browser.cjs` 使用實際首頁 `loadFut` 與成本卡 renderer、既有 CSS 和隔離資料，檢查五筆查詢、變化數字、共享刻度、滑鼠／鍵盤、缺值斷線、零值、單筆／空資料，以及 1512／1220／768／375／320px 深淺背景與卡片高度；正式期貨表僅唯讀查詢，未寫入。

網站為靜態原始碼，無 npm build 目標；執行 JS 語法、瀏覽器測試、差異格式與 API 預算檢查。
