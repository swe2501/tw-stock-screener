# 會員服務補強：帳本、客服、資料攜出、復原與稽核

狀態：本機已實作，隔離資料庫及瀏覽器測試通過；2026-10-23 使用者明確批准後，共用 SQL 已成功套用並通過唯讀驗證（詳 `docs/member-service-deployment-2026-10-23.md`）。後續使用者已指示發布，前端納入本次 234 批次，見 `docs/member-service-release-2026-10-23.md`；實際上線須另核對 Vercel 成功狀態。基準為 UAT `88a16df`。分支 `shared/justy/member-service-completion`。

## 目的與平台相容

網站新增分頁點數帳本、客服時間軸／私人圖片附件、研究備份預覽還原、完整帳號資料匯出、登入方式更換中斷復原、管理角色與規則版本。舊 RPC 的簽章與既有欄位不變；新增 RPC 走既有 Supabase REST，沒有新增 Vercel Function。網站需要先套用新 SQL，再發布前端。舊網站仍可運作，新帳本欄位由 trigger 填入。

iPhone／Android／iPad App 原始碼未修改；仍可使用舊 RPC。新 RPC 不要求 App 立即升級。舊兌換的 task-first 扣點、AI 轉換與使用券啟用已在新 migration 後測試；兩種點數池的扣款使用同一交易關聯。歷史未記錄的異動後餘額顯示無歷史值，不倒算成假數字。

## 資料庫與權限

`docs/database/member-service-completion.sql` 已取得本回合獨立明確批准並成功套用；不能把本次批准延伸到管理角色指派、服務開關或其他 SQL。這會新增八張私人資料表、點數帳本可選欄位及兩個 trigger、受限 RPC、現存使用券條件快照與規則基線。整份為 transaction，可重跑；不建立管理員、不發點、不改既有帳本／券內容、不開啟商品、活動、AI 或付款。

所有資料由 server 以 auth.uid 驗證；管理員讀私人角色表，不相信 user_metadata 或前端擁有者標記。支援 support／finance／rules／audit 分權。補扣點、客服回覆及規則修改需要 JWT AMR 的十分鐘內實際登入證據；刷新 token 的 iat 不能替代重新登入。前端更換綁定先保留其他已驗證登入方式、預先確認 provider 可連結、取得伺服器復原單並寫入本機狀態，才解除舊綁定。

管理員啟用是另一個動作，需要指定網站帳號 UUID 與權限，不能從 Supabase 儀表板登入帳號推定。不提供自動角色 assignment SQL。原生 Supabase Auth API 的存取仍受其專案設定管理；網站 recent-login 防線不宣稱替代供應商全域驗證政策。

客服附件限 PNG／JPEG／WebP，伺服器檢查 signature、大小與帳號容量；沒有公開下載 URL。客服新回覆會留下作者、日期、原狀態及新狀態，會員補充已完成案件可重新開啟。管理補扣點只限任務池；儲值點數不提供人工增減或假付款操作。所有管理異動保存原因、案件關聯、前後狀態與 request ID。

## 備份與匯出

研究備份 v2 包含 SHA-256、帳號、文件、已知雲端衝突版本與可取得截圖。預覽後逐類選擇保留／備份／合併，變更本機前先儲存可還原救援檔；帳號切換、校驗失敗、配額錯誤或預覽後資料變更會阻止寫入。舊 v1 研究備份可讀，但明確註記沒有原始校驗碼與圖片。

完整帳號匯出涵蓋點數／AI／券／案件及附件／任務／挑戰／研究／使用券快照等；大表讀完所有頁，每區列出數量與失敗原因。失敗時標為部分匯出，不宣稱完整。財務與權限資料只匯出，不可由檔案還原。匯出不包含登入 token。CSV 防公式注入。

## 驗證與回復

詳細驗收見 `docs/member-service-completion-2026-10-23.md`；套用後只讀驗證用 `docs/database/member-service-verify.sql`，需比對部署前後帳本總筆數／總點數與服務開關。

前端可回復到先前版本；新增資料表及已產生的帳本／稽核／附件應保留，不能刪除消費者紀錄來回復。SQL 在 commit 前失敗會整體 rollback。成功後如果需停用，先停前端管理操作並另備經審閱的修復 migration，不能重跑舊建表／規則檔覆寫新 verifier。

外部金流回呼、退款／發票、寄信 worker、SMS／OAuth 供應商開通不包含在這份變更。管理核對台已呈現相關異常計數與未開通狀態；`member_payment_orders` 只供未來可信任 server worker 對帳，瀏覽器無寫權，尚未接通任何收款。活動／補償／商品啟用仍需獨立產品決定與批准。
