# 2026-10-26：霧光側籤與導覽圖標

使用者選定第一款霧光側籤，要求再小一點並使用符合各段文字內容的精細圖標。本輪先完成本機修改，未收到這一輪新的 234 發布指令。

- 入口改為右側直式標籤，桌面寬 40px（觸控 44px），展開面板 198px。拖曳僅改變垂直位置，無法離開右邊緣；點擊、拖曳、鍵盤微調各自處理，不因拖完而誤開啟。
- 展開預設關閉；點外部或 Escape 收合。拖曳至右上、右下時面板仍留在視窗內。細光帶慢速滑過，淺色藍、深色霧金，減少動態偏好時停止。
- 六種研究方向採 Lucide 細線 SVG：雷達／走勢／網絡／金融建築／分層／地球。移除歡迎標題與選項中的 emoji，會員權限仍由既有條件判斷，未放寬主力功能權限。圖標授權置於 `apps/web/assets/onboarding-icons-LICENSE.txt`。
- 保留原色 Logo，裁去原圖左右不對稱透明留白，不拉伸圖像。導覽 Logo 高 58px（小螢幕 48px），領航員文字對齊其中心。頭部、書本與中軸不動；翼片以小幅拍動搭配休止，週期 5.4 秒。
- 會員中心新增「會員設定」入口，可關閉新手導覽標籤與首次提醒。設定與位置儲存在此瀏覽器，依會員 ID 分開記憶；頁面明示此範圍，未宣稱跨裝置同步。未增加 API、DB schema、Auth 設定或付費服務。
- 補上導覽對話框語義、鍵盤焦點循環、關閉後焦點復原與既有頁面 overflow 還原。
