# 影片裁切、手機預覽與關閉控制

依JUSTY截圖修正，先本機未發布。圖片／影片同樣支援10–300%縮放與固定版位比例拖曳裁切框；影片讀取metadata取得原始比例，裁切後播放器控制列獨立於裁切viewport，具播放／暫停、進度、靜音與全螢幕。保留原始檔，不重新編碼；媒體前端與API共用media_crop欄位，不需SQL。

手機模式預覽有高度上限和獨立捲動，可收合；真手機寬度預覽先於表單，避免捲到最底才看見。後台afa共用關閉叉號hover只提亮、無圓底與陰影，保留鍵盤焦點。

現況釐清：首頁可多則輪播，其餘版位每次只選符合受眾／時間且優先度最高的一則。公告條與右下卡皆可關閉；公告條在該瀏覽器依廣告id持續隱藏，右下卡關閉後當日隱藏（改依台灣日期），不是看過一次就封鎖當天。說明文字同步更正。

33項論壇Python、既有編輯圖片／影片上傳儲存mock、影片crop metadata與框選保存、手機高度與收合、四版位控制與原有情境檢查通過。沒有操作雲端廣告資料。
