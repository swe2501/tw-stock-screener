# 璞玉官方成分與首頁

公開唯讀服務增加 `/api/prices?action=pristine`，沿用現有入口，無新增部署 Function、DB、Auth 或排程變動。回傳官方 IX0231 價格指數歷史；15 分鐘程序快取，官方暫時不可用時回傳有日期的保存資料及 `history_status=snapshot`。

篩選 POST 可傳 `pristine_only:true`，與既有條件交集；回傳 `pristine_applied:true`。舊客戶端不傳參數，原結果不變。網站檢查回傳旗標；舊服務未套用條件時不顯示結果，含非同步輪詢。

名單來源：https://taiwanindex.com.tw/news/457 ，2026/10/19 盤後生效，採 10/20 起交易日，394 檔、32 產業。完整名單存 lib/pristine_snapshot.json；網站可離線讀取相同快照 assets/pristine-snapshot.js。兩者需一起更新，不能用現今名單倒推歷史。

本版支援成分日期 2026/10/20 至 2027/03/31；2027/04 起先拒絕篩選，待取得新一期官方完整名單。沒有宣稱自動更新成分；下次定審由維護者更新快照、來源、生效日與期限。首頁明示名單日期及價格行情日期，兩者不同。

資料不是推薦名單，既有 App API 參數相容。行情來源為官方公開 records 端點，價格指數（datasets 第 1 組），不將報酬指數與價格指數混用。正式商業資料使用方式須依官方資料條件確認。

本機預覽新增可用埠 49677，能力探測 pristine:true，舊預覽程序保留。首頁入口位於 hpMaintSec 前，企業價值內 pristine_only 選項，支援深淺玻璃、RWD、緩慢流光與 reduced-motion。測試：4 項璞玉規則、既有四式 8 項、預覽來源/收據 2 項、桌面與 390px 深淺互動 4 組；API 12/12。
