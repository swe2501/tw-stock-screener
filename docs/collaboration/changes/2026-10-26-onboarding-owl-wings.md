# 導覽Logo拍翅修正

使用者影片顯示導覽Logo拍翅時身體跟著變形。原本CSS把品牌整圖重複三次再以大範圍polygon裁切，翼片包含頭部附近內容，且1.72寬高比與原圖1789:879不同。

改為等比例SVG容器，仍使用原有明暗PNG品牌圖。左右翼片採排除頭部及書本的獨立clipPath，固定圖層使用互補mask，避免固定舊翼與活動新翼疊影。每個Logo產生獨立遮罩ID，肩部軸點固定，兩翼同步小幅拍動後停歇，取消整個角色上下漂移。重跑導覽的小按鈕保持靜態，減少動態設定下全部停止。

只變更導覽JS/CSS與資產版本，沒有修改導覽內容、偏好、會員旗標、登入或Auth寫入流程，也沒有修改導覽列主Logo。無API、App、資料庫或排程改動。

本機完整網站測試：等比例、遮罩ID唯一、身體不變形、靜止與拍翅兩相、手機／明暗、prefers-reduced-motion；影片僅在本機解碼檢查，未上傳。固定眼睛與書本的像素差最大僅1（渲染量化），翼片區有實際變化。

回復可回退本次導覽資產與版本修改，保留其他Agent的導覽步驟及型態頁成果。
