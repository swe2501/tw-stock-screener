# 訪客預覽與會員功能入口

- 訪客可看首頁與基本 K 圖、切換週期與均線；可進入篩選器版面，但開始篩選前要求登入。
- 其餘研究頁入口、首頁研究按鈕與學習中心入口要求登入；阻擋導覽不新增 history、不強制跳首頁。直接深連結保留首頁預覽並開登入。
- K 圖畫線、圖形、區間統計、進階圖層、匯入匯出、右鍵與複製貼上編輯等互動增加訪客防護；指數圖表獨立畫線亦守護。登出取消使用中的工具。
- 這是本機互動限制，不是安全授權邊界。尚未改動共享 API／DB／RLS；現有公開行情與部分計算入口不能因前端提示就宣稱已受會員授權保護。正式試用前需另驗證後端會員授權、關閉匿名策略執行與資料直取，並處理原有 VIP 籌碼 RLS，方能落實前述僅管理員政策。
- 保留全站邀請門檻 SITE_GATE_ON；不因此全面公開，不改既有會員級別、券、配額或收費。
- 驗證：guest-access.browser.cjs 四種深淺／桌機手機組合，含直接網址、拒絕導覽 history、篩選零增量請求、工具與登入／登出。
