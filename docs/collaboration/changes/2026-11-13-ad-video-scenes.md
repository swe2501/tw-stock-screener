# 廣告影片與版位動畫示意

JUSTY授權完成後推UAT並對齊。

- 首頁影片可選依停留秒數或播放完畢後切換；video_end等使用者播放，收到ended才換下一則，手動暫停優先，隱藏頁面不換頁；影片錯誤回到秒數備援。圖片文字仍使用秒數。舊廣告預設seconds。
- 管理API驗證並公開slide_mode欄位；無新API／SQL，API12/12。
- 選版位與編輯預覽共用網站情境及動畫敘述，涵蓋導覽下公告、首頁市場首屏輪播、篩選表上方、會員中心標題下與右下卡。提供重播、1→2→3操作提示與減少動畫靜態提示，行情／名單為示意。
- 影片預覽使用所選素材與原生controls／playsinline，不強制自動播放／循環，播放時停止其他預覽影片，關閉停止播放，載入錯誤提示MP4編碼／網址。
- 驗證：33項論壇Python、API12/12、編輯圖片／MP4模擬上傳儲存及深淺桌手機、五版位選擇與動畫、四影片版位controls與inline、播放完等待／完成換頁／手動暫停／錯誤備援、原輪播回歸與減少動畫通過。實際雲端素材播放取決於網址可讀及瀏覽器支援，未對真實廣告儲存測試素材。
