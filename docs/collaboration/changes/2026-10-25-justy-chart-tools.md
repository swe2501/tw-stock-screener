# JUSTY K 圖標記與互動修正

範圍：網站 K 圖共用標記、波段分析、框選放大、工具列及區間統計。僅本機修改，未發布。

- 標記持續依圖表實際時間與價格投影重繪；偵測價格軸單獨變更、可見範圍與容器尺寸，不再只用固定延遲補畫。儲存的時間／價格座標不隨縮放改寫。
- 波段折線、兩點黃金分割、三點黃金分割擴展使用原有其他工具配色與原生細線圖示；完整比例列保留價格座標計算及標籤避讓。
- 框選放大以圖表真正的 logical 座標換算，排除價格軸寬度；完成後仍啟用，右鍵或 Esc／按鈕切換結束，觸控完成亦保留。
- 未固定的桌面工具列使用浮動面板，140ms 展開緩衝、320ms 離開緩衝及對稱淡入淡出，避免 hover 反覆改變 K 圖高度；固定模式保留正常版面。手機維持可完整捲動的原位工具列，減少浮動遮擋。支援減少動態效果設定。
- 統計卡以實際放開端定位，反向拖曳亦正確。優先使用未選取一側的無 K 棒空白；不足時維持終點旁的可捲動卡片，減少遮住未選取 K 棒，避免跨入已選取區間。面板允許跨越價格軸邊界以維持短距離；極端窄螢幕才退回外部位置。從上一張卡內容開始拖曳可直接選新區間，按鈕及統計說明仍可互動。

驗證：chart-research-tools 單元與實際瀏覽器測試；新增全部 12 種標記座標不變、矩形實際畫布投影、水平縮放／價格軸／視窗尺寸、連續框選與右鍵／Esc、浮動面板高度不變、統計反向拖曳等回歸。chart-pane-ratios、chart-adjusted-periods 及網站 inline script 語法亦檢查。

不變更 API、Auth、資料庫、App 或正式站；開發紀錄僅保留於本文件及 Git。

- 驗證新增三點幅度與零分母、UI 三次點選完成、統計卡無內部捲動與根數粗體、工具列 180ms 內收合及既有縮放座標回歸。
