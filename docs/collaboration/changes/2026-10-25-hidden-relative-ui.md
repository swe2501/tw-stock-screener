# 真名隱藏式使用介面

真名絕招最後新增真名隱藏式；以 DOM 排序保護與 grid order 保持在未來新增招式之後。方向為強於大盤／弱於大盤，單選。期間提供 5/10/20/60/120/240 交易日、自訂 1～760 日及起訖日期。比較方式為均線／漲跌幅，可複選、AND。

使用者要求前台不顯示算式：採方向、期間、比較方式三步表單，僅留簡單操作提示；數學定義保存在 shared 變更文件及測試。手機日期欄位覆蓋原 checkbox 共用18px寬度，保留清楚文字與點選區。

API 支援標記必須確認，舊遠端後端忽略新參數時不會顯示偽篩選結果。已在獨立 shared 分支準備 API 與近三交易日 SQL，並整合到本機。正式 RPC 需要另行批准套用 docs/database/member-screen-three-trading-days.sql；未執行資料庫 migration；介面與篩選 API 依使用者「一起更新」授權同步 UAT。

驗證：zhenming-hidden.browser.cjs 含強弱互斥、指標複選、週期、自訂日數、日期、永久最後位置、舊後端攔截、深淺色及手機。test_zhenming_hidden.py 驗證 AND、收盤位階、漲跌幅基準、缺資料與無未來資料。PGlite 驗證實際交易日期、週末、舊日／未來日拒絕、去重、會員與紀錄日期。

使用者後續微調：入口改名真名隱藏式（比大小），與其他招式等寬等高；編輯區單獨全寬呈現。方向採紅色強於大盤、綠色弱於大盤。內部選項改成約30px高的小型圓角膠囊，使用淡色背景與細邊框（使用者指定不加底線），保留原生可辨識的單複選與鍵盤焦點，不再使用大片框底。

最後視覺微調：膠囊縮為28px、11px文字，方向各自紅／綠柔光，指標沿主題色微光，僅選取與 hover 顯示、不閃爍；日期與週期高度同步微調，保留減少動態設定。

本機 file/localhost 的隱藏式請求使用 `scripts/serve_hidden_screen_preview.py`（127.0.0.1:49675），僅讀公開行情，避免本機誤連尚未更新的正式站 API。UAT 原有登入保護保留。其他篩選與會員服務網址不變。實際單股／大盤資料試跑通過；空候選回應也保留新版支援標記。
