# 2026-11-03 真名六式（空頭啟動）篩選

分支：`shared/justy/zhenming6` → uat（經 `scripts/collab.py integrate --publish-uat`）

## 變更
- `api/screen.py`：新增 `zhenming6_at()`，以及選用參數 `zhenming6`。
  - 核心條件：均線空頭排列 MA5 < MA10 < MA20、20MA 比 5 日前低（下彎）、當天實體長黑 ≥ 3%。
  - 型態（選用）：`hs_top` 頭肩頂、`m_top` M頭、`box` 箱型跌破、`rising_wedge` 上升楔形、`desc_triangle` 下降三角、`sym_triangle` 三角收斂。在長黑當天或前 5 個交易日內收盤跌破頸線／下緣，之後未站回。
- `apps/web`：真名絕招面板新增六式卡（`assets/zhenming-six.js`、`assets/zhenming-six.css`）。「加上型態跌破」開關控制是否需要型態，型態用下拉選單。
- `scripts/serve_hidden_screen_preview.py`：本機能力回報加上 `zhenming6: true`。
- `tests/test_zhenming6.py`：7 個單元測試。

## 相容性
- 請求參數 `zhenming6` 為選用：`{"enabled": true, "pattern": "none" | "all" | <key>}`。不帶此參數時，行為與原本完全相同。
- 參數 `pattern` 不合法時回傳 `{"error": "真名六式的型態選項無效。"}`。
- 回應新增欄位：
  - 每檔股票的 `zm6`：`black_pct`、`stop`、`ma5`、`ma10`、`ma20`、`cover_season`；有型態時另含 `pattern`、`pattern_key`、`level`、`break_date`、`day_n`。
  - 頂層的 `zhenming6_applied`。
  - 既有欄位不變。
- 沒有資料庫、Auth、排程或付費服務異動。只使用既有的 `price_window` 資料。
- 不使用 `scripts/chart_pattern_rules.py`，因為 Vercel bundle 不含 `scripts/`。型態判斷寫在 `api/screen.py` 內。
