# AI 研究室部門派工

## 行為與範圍

新增任務中心及部門名片「指派任務／查看部門任務」，沿用 32 部門目錄，物流維持停用。支援人工工作與 Claude 研究／草稿、截止日期、驗收條件、卡點回報、成果、退回、取消及前置任務交接。執行進度取自回報／狀態，不以動畫或時間推算百分比。

## 網站／App 相容性

沒有增加 Function、沒有更動現有 API URL／Auth 規則／Windows 排程。api/auth 的新 admin_office_tasks_* 動作位於既有管理者 JWT 驗證後。不更動 api/alert 或擴大總管 BOSS_TOKEN 權限。原 admin_office 與總管報告保持相容；App 無需改版。

任務中心只在 UAT 分支啟用，正式部署拒絕此功能。舊網站與 App 不會受到新任務動作影響。3D 部門透過同來源且核對 source 的 iframe 訊息開啟任務中心，不傳 token。原排程看板保留。離開研究室銷毀任務 dialog、輪詢及 iframe，原像素動畫只在可見排程看板運作。

## 持久化及資料邊界

沿用既有 admin_settings：每筆任務一個 office-task-uat-v1-<uuid> key，執行端心跳為 office_task_worker_uat_v1。無 migration、無 seed、無 RLS／Auth 變更。準備及測試不寫入 Supabase。上線使用與真人驗證會新增這些管理紀錄，需依使用者授權執行。

每筆使用 revision 加 updated_at 的原子 PATCH 條件，避免兩名管理者或重複執行端覆蓋；建立使用 UUID 請求去重。大型成果不放入 CAS URL。讀取異常／寫入未確認／競爭失敗都不回報成功。前置必須驗收通過才可領取；舊租約、取消或過期後不能提交結果。

## 執行與費用

Claude 執行器獨立於既有總管與 Windows 排程，每次只處理一項，沒有自動重試付費工作。使用已安裝的原生 Claude CLI 與現有 claude.ai 登入，safe-mode、只開 WebSearch/WebFetch，停用 MCP、技能與自訂程式鉤子；不具 Bash／Read／Edit／部署／郵件工具。只能產出公開研究或文件草稿，成果必須由人驗收。

本機模式沿用現有 boss_runner 的服務環境直接存取管理紀錄，避免 UAT Vercel 部署保護重新導向；資料庫服務金鑰只在 Python 父程序，不傳 Claude 子程序。本機執行端不能透過 worker 動作自行驗收，也未擴大雲端總管的資料存取範圍。

單項表單預設 US$0.50、可設定 US$0.05–10；執行端每日估計承諾額度預設 US$0.50，可由明確啟動參數調整。每日額度為保守估計（包含當日被更新任務的歷史已回報及保留費用），非跨機器交易式帳務上限；實際帳單／訂閱額度仍以 Claude 為準。每次模型呼叫帶 max-budget-usd。無回報費用時保留該次預算並標示未確認，避免無限制重跑。

## 驗證

25 項離線 Python 測試：生命週期、版本／原子競爭、前置驗收、權限、取消、過期、預算及模擬模型成功／失敗／取消／逾時／結果傳送中斷。瀏覽器測試覆蓋手機桌面明暗、建立與回報、逐項驗收、交接、XSS 安全顯示、部門 iframe 整合與清理。真人／真模型端到端驗證另行批准，並保留可核對的 UAT 任務紀錄。
