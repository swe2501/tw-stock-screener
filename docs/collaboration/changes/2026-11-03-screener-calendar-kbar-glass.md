# 淘金篩選：日曆按鈕、K棒型態提示、玻璃介面精緻化（2026-11-03）

JUSTY 要求，justy-layout → uat。只改視覺與互動，篩選邏輯、資料與 API 不變。

## 淘金篩選
- 選股日曆收進「今日選股紀錄」列：圓潤膠囊按鈕，圖示顯示今天月／日；點擊往上浮出日曆（Esc、點外面關閉），點日期仍開原本的當日紀錄視窗。工具列的「選股日曆」連結在有此按鈕時隱藏。
  - `screen-inline-calendar.js`：偵測到 `.sl-today-summary>summary` 時改用浮出模式；沒有時維持原本內嵌日曆（其他頁面不受影響）。
- 今日選股紀錄列改成單行窄膠囊。
- 結果表格改由 `#resultsArea` 同時負責上下左右捲動，橫向卷軸固定在可見區底邊（今日選股紀錄正上方）。
- K棒六個條件滑過時顯示型態示意卡（`kbar-hint.js/.css`）：紅漲黑跌、深色模式黑K加淺色框；吊人線為 T 字線（開＝高＝收）；吞噬與母子線的小K實體置於大K實體正中間。僅滑鼠／鍵盤焦點觸發，觸控不顯示。

## 玻璃介面（glass-skin v4）
- 修正：篩選面板標題（`.sc-hd a[role=button]`）被套上按鈕外框，造成一格一格白框。
- 環境光背景（柔和多色光暈、緩慢漂移），玻璃面板改雙層高光邊與更通透的霧面；篩選面板、送出鈕、工具列、頁尾一致圓潤。
- 換頁時內容依序由下往上浮現；開關玻璃時用 View Transition 整頁柔和轉場；會員中心開關加入液態按壓感。
- `prefers-reduced-motion` 時關閉所有動畫。

## 追加（同日）：玻璃可讀性與動態
- 環境光改用品牌色（淺：品牌藍＋銀白；深：深藍＋淡金）。
- 全站浮層（側邊抽屜、彈窗、浮出選單、提示卡，約 30 種）在玻璃模式改「厚玻璃」近不透明底，後方以模糊＋淡暗遮罩，修正 ETF 研究卡等文字與背景疊在一起看不清。
- 頁尾免責聲明列改不透明底；玻璃面板提高不透明度；輔助小字加深。
- 玻璃動態（參考使用者提供的 Glassy Dashboard 影片）：換頁時卡片由模糊到清晰、微放大浮上、依序錯開；側邊抽屜帶霧滑入、內容依序浮現；彈窗從 96% 帶霧浮上；下拉從按鈕位置展開。只在玻璃模式、只改視覺，`prefers-reduced-motion` 時關閉。

## 追加：玻璃模式數據動態（glass-motion.js）
- 半圓儀表弧線由 0 畫到數值、亮點沿弧滑動、中間數字滾動；SVG 走勢線由左畫到右、面積淡入、端點輕彈；SVG 長條由底依序升起；卡片內大數字（≥20px）滾動；百分比寬度的 HTML 長條展開。0.8 秒。
- 捲進畫面才播放，每次進頁面每個圖只播一次（以 DOM 路徑辨識，資料刷新重繪不重播）；網站自行更新數字時立即交還控制。
- K 線圖每次載入以 clip-path 由左往右刷出，不碰 Lightweight Charts 與互動。
- 文字連結型按鈕（etx-stock-link、etx-info-link、mj-link）移除全站按鈕陰影造成的框（四種外觀皆適用）。
