# K 圖官方公告輪播

在 K 圖標題下增加精簡公告列，提供官方原文、日期、來源、上一則／下一則及暫停。每八秒輪播，滑鼠停留或鍵盤焦點在公告內暫停；偏好減少動態者預設暫停。沿用網站明暗色彩，手機可換行，不建立圖表子捲軸。

沿用登入驗證的 POST /api/auth action=official_announcements，新增 context=chart 與嚴格驗證的 code。讀取近七日：本檔公告透過 official_announcement_securities.observed_code 精準 JOIN；市場政策依來源類別白名單查詢，明確分開標示，不推論與該股的直接關係。每類最多 20 筆，公開讀取上限仍為每類 50。未新增 Function、表或修改權限，沒有啟動其他排程。

僅圖表開啟且分頁可見時讀取，五分鐘更新；失敗一分鐘後重試。個股切換中止舊請求並核對股票／登入者；登出清除公告。不使用 HTML 渲染官方標題，只允許 HTTPS 原文連結。市場政策跨來源去重沿用既有規則。

驗證：九項 Python 測試通過，API 入口 12/12；1440 與 390 寬度瀏覽器測試涵蓋請求競速、切換、減少動態、來源連結、文字安全、登出與關閉。唯讀 Supabase 真實 JOIN：2330、2395、00406A 均回傳 200，各四則市場政策、零則直接公告；沒有捏造個股消息。
