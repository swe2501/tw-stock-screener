# 本機付款介面可操作測試

JUSTY 要求能實際試填付款介面，並對齊常用本機 billing 網址。本次只本機修改，未要求發布。

- 檔案／localhost 或管理員畫面提供明確「測試付款流程（不扣款）」開關，預設關閉；不改正式付款開關。
- 啟用後可填測試卡號 4111 1111 1111 1111、未來有效期限、3 碼安全碼及測試姓名，試驗證／處理／完成動畫。退出後重新停用輸入及付款；不保存卡號。
- 測試 click 在所有真實付款分支之前 return；LINE Pay 與超商僅顯示示範結果，不建立訂單、不跳轉金流、不綁卡、不扣款。頁面說明清楚標示為測試。
- 商品服務暫時無法讀取時，測試模式可用獨立「付款流程測試」示意選項，不當作真實上架商品。
- 完整網站 mock 的深淺色桌機／手機：填測試卡與完成動畫、退出鎖定、付款 request 為零；原付款 8 項檢查通過。另補商品服務失敗時的獨立測試。

不更改資料庫、金流服務、會員資料或正式綁卡能力；本機預覽不代表 UAT 已發布。
