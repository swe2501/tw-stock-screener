## 最新結構校正

使用者進一步明確指定：市場觀察下的「不籌吃穿」應是與其他項目相同的單一圖示入口，非巢狀展開選單。進入頁面後才呈現三個共用切換按鈕：主力訊號、分點回測、追蹤觀察站。保留 sig／brank 既有路由，新增 brokertrack 頁面承接原追蹤內容與資料讀取；追蹤存取仍要求原有 owner 或 selltrack 解鎖，不修改驗證或資料 API。桌面／手機及深淺色按鈕均驗證，追蹤內容不再另開遮罩彈窗。

## 主力訊號日期區間與工作台整理

- 日期區間入口放在單日左箭頭的左側，以收合式起訖日期選擇器套用；限制於目前已載入的日期上下界並明示涵蓋範圍。不額外聲稱完整歷史、不修改 API 或查詢權限。
- 日期區間含起訖日，切換交往／分手保留範圍；返回單日或使用箭頭可恢復逐日瀏覽。區間列出各筆日期，K 圖開啟時使用該筆日期。雙榜交集以日期＋分點＋股票配對，避免跨日誤配。
- 實測勝率維持原本整體統計，區間模式明示其不隨日期變動；不修改勝率計算。
- 依使用者後續要求統一訊號／回測工作台視覺：細邊框、主題底色、清楚主標與副標、三個切換按鈕及選項間距。
- 主力訊號在非統計頁籤顯示目前所選日期、方向、榜別的訊號筆數、不同分點家數與股票檔數；均來自當前呈現結果，空結果為零，不提供買賣建議。
- 實測勝率、簡單回測榜、雙榜交集表格，將勝率、已滿筆數與未滿筆數分行；固定數字對齊及行距、統一表頭與手機橫向表格容器。保留原始數值與互動。
- 驗證：signal-date-range.browser.cjs、broker-statistics-layout.browser.cjs（含深淺色、桌面及手機），以及既有語法與儲存保護測試。仍僅本機修改，未推送。

## 日期按鈕微調

依使用者要求縮小日期區間入口（12px 字、14px 圖示、約30px高、較小內距），覆蓋全站 summary 字級，與旁邊箭頭維持協調。點選選單外任意空白／其他內容即收合；內部選日期及按套用不受影響，收合不清除已套用區間。以原日期區間瀏覽器測試加入外點關閉、內部操作保持開啟與入口高度驗證，涵蓋深淺色及手機。
