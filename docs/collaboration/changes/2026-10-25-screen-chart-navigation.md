# 篩選結果 K 圖逐檔瀏覽

只在篩選結果表格開啟的 K 圖顯示上一檔／進度／下一檔。依使用者最後指定，貪婪指數與控制是兩個相鄰獨立框；右框使用小型圓形箭頭與中央進度，整組置中，沿用深淺主題色。無儀表資料時保留篩選結果標頭空間，避免壓到下方分頁。

結果表格每次依現行排序提供清單；開圖時複製清單，後續背景表格重畫不改變當次瀏覽順序。首尾停用對應箭頭；載入時暫停點擊，失敗後可繼續上一檔。一般搜尋、會員、分點、指數等入口與關閉 K 圖都清除瀏覽來源。

切換沿用既有畫線儲存／載入、請求序號與圖表載入流程，額外保留週期及還原模式。各檔畫線仍各自儲存；不變更 API、資料庫、會員權限或全站其他入口。

驗證：screen-chart-nav.browser.cjs 使用實際圖表程式，包含排序、首尾、還原週 K 保留、畫線隔離與復原、載入失敗、四位數進度、非篩選入口隱藏、獨立框間距、置中與深淺手機版。chart-adjusted-periods.browser.cjs 驗證現有週期／還原模式；chart-watch-sync.test.cjs 驗證腳本解析與會員保存邊界。
