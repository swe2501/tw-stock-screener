# 先見 AI Office：獨立 3D 外觀預覽

## 本次範圍

- 獨立入口 `apps/web/ai-office.html`；既有後台 AI 研究室加入大廈入口，直接內嵌探索，並可切換排程看板或另開完整視窗，保留原排程看板與真實狀態。未加入公開導覽或變更會員驗證。
- 原色貓頭鷹品牌、完整漸收玻璃帷幕、銀色立面、香檳金結構線、斜面冠部與曲線裙樓。日景太陽、雲層與城市剪影；夜景月亮、星空與窗燈。
- 滑鼠／單指旋轉、滾輪／雙指縮放、部門聚焦、全景復位、自動環繞。
- 32 部門分為 8 層，每層最多 4 部門、各自配色與家具。頂層為執行長／總經理與策略治理，依序資安法務、工程資料、行銷成長、創新產品、市場商務、服務組織及營運供應鏈。
- 點選樓層才展開室內，包含部門 62 名與大廳 4 名不同膚色及男女外觀的商務人物與輕微自然待機動作；物流空間不放工作人物。
- 部門職責說明、窄畫面折疊清單與標籤避讓。
- Instagram 參考確認廣告團隊及預約團隊；其餘為組織規劃補充，未聲稱已完整辨識影片所有部門。
- Three.js r160 MIT 引擎與授權隨頁面保存；Logo 以原圖資料 URI 用於 3D 貼圖，讓 file:// 預覽不觸發跨來源貼圖問題。頁面不依賴外部 CDN 或字型。
- 物流部預留且停用；所有部門均未啟用工作服務。畫面標示外觀預覽，沒有模擬正在工作的 AI、任務數或成本數據。

- AI 研究室預設內嵌金融大廈；原有排程看板與真實心跳另設切換，未刪除。
- 32 張部門名片提供職位、職責與預計交付；物流仍未啟用。
- 新增品牌接待大廳，沿用原色 Logo、接待區、座席及三面研究展示牆。
- 三條可逐步探索的協作路線：新功能開發、研究報告、品牌活動；每步可前往負責部門，不觸發任務。
- 協作視窗使用簡潔流程列表與細分隔線，取代多色圓角方塊及口號文案。
- 桌機與窄螢幕驗證名片、關閉／Escape、三種路線、部門跳轉、大廳及後台切換。

## 後續自動化與 Google Cloud 設計方向（未部署）

3D 介面與執行服務分離。關閉電腦或關閉網頁後，只有已部署到雲端的任務服務能持續工作；單靠此 HTML 不會執行自動化。

建議構成：

1. Cloud Run service 提供經身分驗證的任務入口；需完成批次的工作可使用 Cloud Run jobs。
2. Cloud Scheduler 觸發定時工作，Cloud Tasks 管理非同步派送與有限次重試。
3. 持久資料庫保存工作狀態、檢查點、部門設定及稽核紀錄；依任務 ID 去重，避免至少一次派送造成重複副作用。
4. Google Drive 可作文件協作來源；Cloud Storage 可保存模型資產與工作產物。兩者不是執行引擎。
5. Secret Manager 保存金鑰；各部門使用最小必要服務權限。
6. 長時間任務由可恢復的雲端工作流程管理，不使用網頁計時器充當排程，也不假設 HTTP 請求結束後仍會無限執行。
7. 正式發布、對外訊息、付款和資料刪除等行為需有獨立批准步驟。
8. 任務需有 token／費用上限、逾時、重試上限、停止開關及錯誤通知；雲端預算告警不能當作自動硬性停費機制。
9. 物流 enabled=false；不得因建立部門外觀而串接供應商或開始出貨。

## 外觀與 AI 模型

本版 3D 幾何為程式建模，沒有大型語言模型或 GPU 需求。未來 AI 模型需依繁體中文、研究引用、工具操作及成本實測選型；可用模型 API 或雲端託管的開放權重模型，不必每個部門各常駐一個模型。尚未挑選或下載任何 AI 權重。

## 尚需使用者提供／確認

- Google Cloud 專案與預算範圍，開通付費前另行確認。
- 僅內部使用的帳號／角色與合夥人權限。
- 首批要自動化的工作、週期、資料來源與驗收條件。
- 模型提供者、工具權限和費用上限。

本次沒有建立雲端專案、啟用帳單、變更 Auth／正式資料庫、排程或發布。
