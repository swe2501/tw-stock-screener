# 生日禮 300 點與慶生畫面

使用者核准：生日自動入帳，不用優惠碼；溫馨可愛動畫播完再顯示祝福；同一帳號每年只能一次，修改生日不得重發；右上角關閉符號不要框。

## 共用服務

- 共用分支工作區：`justy-member-lifecycle`；migration 為 `docs/database/member-birthday-v6.sql` 和 `member-birthday-v6-schedule.sql`。
- 2026-11-07 已套用 Taiwan stock2。pg_cron 每小時第 5 分鐘檢查，生日當天首次檢查為台灣時間 00:05。第一次執行沒有符合生日的帳號，原有 6 筆 ledger 保留。
- 完成信箱或手機驗證、已填有效生日的會員，每年 300 任務點數。首次保存的當年度生日鎖定，之後修改在下一年度首次檢查時使用；2/29 遇非閏年於 2/28 發送。
- 年度收據沿用 `birthday-v1` 與年鍵；與舊領取紀錄共用防重複，不替已領舊生日禮的同年度帳號補發第二次。點數獨立一般每日 60／每週 300 額度，透過 v5 點數 lot 有效一年；未新增生日券。
- 批次、手動相容入口都使用同一帳號錢包鎖與年度收據；活動 task 停用可停止未來新發放。排程與發放 helper 禁止一般會員執行。
- 既有站內通知從 ledger 自動呈現生日描述；不寄 Email/SMS，不使用 AI 或外部付費 API。

## 網站

- 新增 `member-birthday.js/css`。只讀取已發放的伺服器收據，沒有收據就不顯示生日禮。
- 貓頭鷹浮現、禮物輕開、星光柔和亮起，約 3.2 秒後顯示祝福與實際到期日。可略過、關閉；減少動態偏好直接顯示文字。
- 每年度首次顯示後記錄伺服器已讀，跨裝置不重播；登出即關閉。正在登入或有其他對話框時延後出現，不搶焦點。
- 深色使用淺色貓頭鷹輪廓與暖金；淺色使用原 logo 配色與藍色。叉叉無框，鍵盤焦點改為柔光。
- 任務與點數、點數帳戶共用規則新增生日禮條目，生日任務顯示自動送達而非要求手動領取。
- 網站畫面目前只在本機更新，未推送 JUSTY/UAT/prod。
