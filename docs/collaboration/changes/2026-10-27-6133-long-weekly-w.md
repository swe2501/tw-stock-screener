# 金橋多尺度週 K W 與五年歷史

金橋 6133 補入使用者確認的兩組歷史 W。大型左端延伸至 2022-08-26 高點，另一組涵蓋 2025 年兩底與年底回升。兩組仍須左右端觸及中間頸線；不放寬全站形狀規則。大型右端採 2026-01-30 最高價觸線，並非收盤突破，不列入近期突破或形成中。

圖表保留預設三年範圍。遇到五年研究紀錄超出視窗，提供載入五年週 K 按鈕。既有 chart API 新增 5y 日資料回溯天數，沿用原有前端週彙整，不增加 Function、資料庫、Auth 或付費推論。App 舊請求及其他 range 行為相容。

驗證：全市場資料與兩組精確 OHLC 錨點核對；6133 瀏覽器測試確認三年一組／五年兩組共四條線及 checkbox 清除；選股頁 34 檔歷史 W、一般圖表防護與 API 12 支上限。
