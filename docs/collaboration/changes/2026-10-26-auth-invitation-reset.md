# 2026-10-26：登出後不再停留邀請碼子畫面

使用者回報登出後看到「朋友的邀請碼」，一般登入欄位被隱藏。原因是保存的邀請碼會在初始化時自動展開 details，且重新開啟登入視窗時沿用其 open 狀態。

- 保存的邀請碼只預填，不自動開啟邀請碼子畫面。
- 每次正常開啟登入／註冊視窗時收合邀請碼；登出成功、token 已移除時也清理該子畫面的顯示狀態。
- 保留既有邀請碼及使用者手動開啟入口，不刪除邀請紀錄，不更動邀請資格或獎勵判定。
- 不更動登出請求、伺服器確認、登入後首頁路由、會員中心綁定原頁規則或手機驗證要求。

驗證：既有玻璃登入完整瀏覽器測試加入「初始化有保存代碼但顯示一般登入」、「手動展開後登出」、「重新開啟回一般登入且代碼仍保留」回歸檢查。深淺／響應式登入、手機驗證與同會員綁定、OAuth 首頁／綁定原頁測試通過。隔離服務驗證，沒有操作真實會員。
