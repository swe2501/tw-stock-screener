# 首頁外資結算成本卡：依設計示意實作

範圍：網站首頁成本卡及期貨四卡對齊。保留既有點數帳戶、五日走勢等未提交修改；本次無提交、推送、正式資料庫或 API 變更。

- 依使用者確認的深淺主題示意，加入層疊裝飾波形、柔和掃光、距估算成本點數、精確比例價格刻度、日夜盤選擇及行情日期。
- 依後續修正，移除左上角圖標，使用與左邊相同字型、27px／800 主數字及等寬數字設定。右上角月份為無色塊、無陰影、正常不透明度的文字，避免被舊全站 header 樣式遮住或在手機隱藏。
- 四張卡共用標題、主要數字、中段資訊／波形、圖表資訊四列；外框與內容列對齊，不因成本卡獨立增加巨大留白。既有三張卡內容以 `.fs-context` 分組，數據與說明保留。
- 波形明示「光效示意」，不是歷史行情；數字與刻度仍採既有結算估算及期交所已公布日／夜盤資料。缺基準或價格時不產生假的比較點。名稱為「外資結算成本估算」，提示非實際進場成本。
- 刻度自動包含成本上下 500 點及目前價格，依數值同比例定位；極端距離時收起過近文字，保留刻度與 title，避免重疊。成本標記與價格標記分層顯示，價差為零亦可辨識。
- 日夜盤仍由原有共同狀態控制，與詳細研究頁同步。詳細頁的原有火箭／流星／拉鋸動畫與基準資訊保留。
- 光效採 CSS 掃光、波層呼吸及價格標記 halo；固定數字不位移。遵循 prefers-reduced-motion，縮減動態時停用動畫。
