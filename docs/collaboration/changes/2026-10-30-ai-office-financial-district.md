# 金融街場景與探索操作調整

- 保留先見品牌、32 部門、既有角色狀態與原工作紀錄。
- 樓層導覽、探索分頁、攝影機工具與底部介紹分成獨立區域；低高度視窗的樓層列可自行捲動，不向上下操作區溢出。
- 全景移除重複的樓層浮卡，改由左側導覽選層；部門室內標籤保留。
- 尖頂改為八面收束的玻璃冠部與纖細塔尖，增加側面窗燈、柔和的塔冠光暈及細微立面照明。鄰棟高度降為原規劃的七成，確保主塔最高且最醒目。
- 新增原創金融街廓、退台鄰棟、道路、行穿線、路燈與六輛緩慢行駛車輛。計程車偶爾停靠入口前方，入口燈光同步變暖。靠近視線的鄰棟會淡化，避免遮住主塔。
- 白天慢速雲層、遠方飛鳥；夜晚星光與偶發單顆流星。減少動態模式停用車流、飛鳥及流星。
- 街景重複幾何採 InstancedMesh，降低繪製呼叫。隱藏頁面暫停場景更新，部門室內不顯示城市街景。
- 左鍵旋轉、右鍵／Shift 拖曳平移，亦提供「旋轉／平移」選擇。滾輪以指標位置縮放，雙指縮放與平移共用穩定焦點；全景可復位。
- 沒有新增 API、資料庫、AI 任務或對外服務。

驗證：`tests/ai-office.browser.cjs` 保留既有部門與狀態整合測試；`tests/ai-office-district.browser.cjs` 驗證三種視窗尺寸的操作區分離、放大後平移與旋轉、復位、車流、白天飛鳥、實際夜間流星及減少動態模式。人工檢視深淺與窄畫面截圖。

設計主題採「展翼的書頁」：不對稱雙折面尖冠、兩道書脊般的上升金屬縫、翻頁形入口雨棚，以及同語彙的小型廣場雕塑。此為原創視覺設計，不宣稱獲獎或由特定建築師設計。

右側部門總覽整體字級放大（桌機部門名稱 14–15px、標題 21–22px），同步加寬欄位、調整行距與組數標籤。平板與窄畫面採各自字級，保留獨立清單捲動，不遮住底部操作。
