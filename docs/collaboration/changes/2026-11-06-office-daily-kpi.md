# 部門每日職責與真實 KPI

使用者先採每天一次全公司巡檢與提案，另要求全天雲端成本估算，KPI 持續追蹤。

- 建立 32 部門職責／交付物／下一站與業務指標目錄；物流維持停用。
- 部門工作室加入「每日工作與 KPI」區塊。只由已載入任務 history 的實際驗收時間計算最近七日與前七日交付量、準時驗收率，另列卡住／失敗任務。業務指標尚未接資料則明示未串接。
- 資料未取得與零件已驗收區分；限制樣本與非全量紀錄清楚說明。不增加 API、不啟動模型、執行器或資料庫寫入。
- 本聊天已排每日 09:30 巡檢，讀取現有授權資料並回報，不自動寫回網站工作室；每週一三主題排程保留。沒有宣稱既有本機排程可在關機後運作。
- 單元驗證 32 部門、物流、時間邊界、樣本不足與輸出安全；工作室 browser 驗證真實紀錄、深淺色 1440/390px、快取、工作人物及任務入口通過。
- browser 測試移除「舊排程按鈕已隱藏」的過時假設，改驗證目前任務中心可見；不修改現行後台按鈕行為。

僅本機修改，未推送或部署。全天雲端及模型付費部署仍未執行，價格估算以官方 Cloud Run、Cloud Scheduler、Claude 價目表查核後在聊天提供，非實際帳單或營收承諾。
