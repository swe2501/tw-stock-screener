## 每次只讀必要內容

1. 初次接手讀根目錄 `AGENTS.md`、`docs/collaboration/README.md`、本檔及自己的交接檔；涉及子目錄時遵守其適用規範。規則有變才重讀。
2. 先確認工作目錄、分支與 `git status`，再用 `rg` 找本次功能。不要預先讀完整巨型 HTML、全部歷史對話、所有部門文件或全部交接。
3. 小改動只跑相關驗證；已有通過結果且程式未變，不為填報告重複跑。回報只寫結果、驗證、限制及下一步，不重述長篇歷史。
4. 任務完成更新自己的交接檔：日期／問題／修改檔案／驗證／提交與部署狀態／待辦。沒有證據就寫尚未確認，不把舊對話當作實際完成證據。

## 避免聊天室互相覆蓋

五個聊天室共用同一個網站資料來源。預設一次只讓一個聊天室修改共用 checkout；其他聊天室可討論或唯讀。不要自行建立五個 worktree 或五條常駐分支。需要同時開發時，先由使用者授權隔離工作區，再依協作規範辦理。發布一次只由一個聊天室執行，先核對其他待發布工作，不能把並行發布當作省時方式。

全站維持 FORESIGHT 的深淺色、清晰文字與適度玻璃感；保留既有品牌配色，避免重疊與過度透明。開發紀錄只放文件與 Git，不顯示在網站。會員端 AI 保持關閉；金融大廈自動排程維持暫停。
