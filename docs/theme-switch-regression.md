# 深淺色切換顯示修正

2026-10-18：反覆切換集團研究的 5／10／20 日與圖卡／條列後，原 `ensureContrast()` 會在 `button.on` 留下 `data-pro-tone`。按鈕失去 `.on` 後，舊屬性仍以 `!important` 覆蓋文字顏色；換主題時又會在背景轉場途中取樣，因此造成前景與背景同色。隔離瀏覽器回歸已重現原錯誤（文字對比約 1.01:1）。

一般控制項及語意標籤改由現有 CSS 主題變數決定文字，不再被全域黑白字推斷覆蓋。自動對比僅保留給實際填色的題材熱力圖、產業熱圖與貪婪色塊。顏色解析使用瀏覽器 Canvas，支援 `color(srgb ...)` 等格式與透明度混合；採黑白前景中較高對比者。色塊樣式更新會重新檢查，一般元素樣式更新不觸發全站重算。

`assets/site-theme.js` 集中登記各處 Lightweight Charts 實例；主題改變只更新既有畫布的背景、文字、格線及邊線，不修改 series 資料、可視區間、捲動、縮放或選取。移除實例時釋放登記。首頁與外資空單頁不再為換色而重建圖表。會員策略圖也使用相同建立入口；獨立載入策略模組仍支援既有建立方式。

`tests/theme-switch.browser.cjs` 使用離線網路資料驗證反覆／快速切換、選中／未選中控制項、五類共用分頁元件、動態熱區及手機寬度。設定 `LIGHTWEIGHT_FIXTURE` 為網站原有的 4.1.3 runtime 本機檔案時，另以真正圖表驗證資料與可視區間保留、主題色同步及移除後再次切換；測試不使用真實帳號或修改線上資料。
