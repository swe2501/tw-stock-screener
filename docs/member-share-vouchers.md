# 待啟用使用券：2026-10-19 已確認規則

此變更僅準備與隔離測試，尚未套用共用資料庫，活動仍不會自行開放。

- 每個新帳號在建立帳號的同一筆交易中核發隨機、不重複的專屬邀請碼；既有會員經本人 RPC 補齊，不改已發代碼。新增獨立 academy_provision_invite_code trigger，不修改原有 triggers；這一項亦須在正式套用前明確批准。
- 每個新會員可在註冊後補填一次介紹人；同一被邀請帳號只能歸屬一位邀請人。既有 unique(invitee_user_id) 與 RPC 檢查保留。
- 沿用每滿 3 位有效新會員核發一張 7 天券；5 位則核發一張並保留 2 位進度。使用者尚未要求把門檻改成 5 人。
- 誠信分享任務每帳號一次 3 天券。不能技術驗證 IG 私訊收件人；有效邀請另外依已驗證會員計算，不靠前端分享次數。
- 核發時只建立 ready 券，不建立使用權。期限＝核發時間在台北時區加一個日曆月，月底自動取有效日期（例如 1/31 → 2/28）。
- 會員到「禮遇與優惠券」按開始使用，伺服器交易內驗證本人、狀態及期限，才建立完整 3／7 天使用權。同一券重試與雙視窗只會建立一筆。
- 11/18 啟用、11/19 是啟用截止：仍有完整 7 天到 11/25。截止後未用券不可啟用。
- 每張券從實際啟用時起算；已有使用中券時會先顯示期限與重疊提示，會員明確確認才啟用下一張。囤券不等於已增加有效期限。
- 已發出的舊權益、一般優惠碼、非使用券禮遇保留原規則；不撤銷舊獎勵。

## 功能選擇待營運方決定

| 分類 | 現有內容 | 現況 |
|---|---|---|
| 分享研究工具 | 外資空單溫度計、大盤多空廣度 | 已有 research_tools 接入，可作首批券範圍 |
| 一般會員 | 自選、筆記、交易紀錄、策略回測、會員個資 | 沿用原帳號功能，無須使用券 |
| 一般研究 | 指數、產業／題材、ETF、新聞、篩選器 | 沿用現有入口；本次不新增鎖定 |

| 管理／算法 | 管理員、私有公式／算法 | 不可由推薦獎勵提升權限 |
