# 九角色五階段互動與 3D 美術交接

狀態：九角色的五階段原畫、逐段播放停留、每階段五類互動／道具已接入 **2.5D**。點角色使用每階段獨立的隨機袋，五次觸發涵蓋五類，不更動目標／交易資料。預覽入口預設原畫；幾何韭菜 3D 不符合原畫精緻度，使用者未驗收，不得宣稱九套正式 3D 已完成。

## 動作與素材邊界

目前是五種 WebGL 局部變形模板，加上逐階段名稱、幅度與道具配置；並非 225 段手工骨架動畫。五類為 pat（致意／碰觸）、offer（分享／召喚道具）、play（舞蹈）、care（照料／浮空凝神）、cheer（跳躍／慶祝）。SVG 道具有各主題造型與金屬／珠光漸層；不把它們稱為真 3D 道具。

正式製作需依 assets/goal-art 的原畫，完成九主題 × 三種外觀 × 五階段，共 135 個 stage/persona 資產。每階段需五個 lifecycle clips 與五個 interact_* clips；骨架、材質、毛髮、道具持握／接觸都須美術驗收。不得把測試幾何體、貼圖平面或影像影片當作合格角色模型。播放器及機械驗證規格見 assets/goal-models/README.md，manifest 目前仍 0/135。

已查找可用外掛，未找到已連接且能直接交付此批綁骨模型的工具；影像／影片工具不能代替角色建模與動作交付。本次未外傳原畫、未購買或使用付費 3D 服務。
